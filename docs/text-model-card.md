# Daily Pause local text model

`english-centroids-1` is a small English TF-IDF nearest-centroid classifier implemented in `JournalTextModel.java`. It is not a generative language model. It runs on the CPU without a native inference library, network request or model download. The bundled reference sentences were manually authored for Daily Pause; they contain no user journals or external dataset.

The model uses normalized unigram/bigram vectors and label centroids for work, relationships, family, social connection, sleep, exercise, outdoors, physical health, money, study, hobbies and mindfulness, plus positive/negative/neutral wording. Topic classification permits multiple labels and ignores negation because a negated experience still mentions a topic. Sentiment uses limited negation features and excludes the future-needs field. Cosine thresholds and margins allow abstention. Neutral is a competing class; no confident positive/negative label is reported as unknown, rather than treated as negative or a zero mood.

The app correlates detected mentions with self-reported daily moods. It cannot determine whether a topic caused a mood, whether an activity actually occurred, or whether a wish describes an experienced event. Heap labels provide additional theme context. Tone estimates are secondary context, not replacements for mood ratings.

Automated tests include held-out English examples for multiple themes, positive and negative wording, negation that must not become positive, needs-only text and unknown/non-English text. These are regression checks, not a representative accuracy benchmark. No population-level accuracy, fairness, clinical validity or device performance has been established. Sparse authored examples, vocabulary gaps, misspellings, sarcasm, figurative language, code-switching and mixed feelings can lead to missed or incorrect labels. Avoid interpreting an empty report as absence of a concern.

Reference text and source are reviewable in the repository. Changing preprocessing, references or classification behavior requires a model-version bump so cached reports are regenerated. Extracted classifications are held only during calculation; the private report cache stores human-readable summaries, never a second copy of journal text, and is excluded from encrypted backups. The existing local journal database is not additionally encrypted; the app PIN controls interface access and Android secure-window protection remains enabled.
